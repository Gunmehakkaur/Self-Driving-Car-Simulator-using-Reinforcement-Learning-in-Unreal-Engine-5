**Self Driving Car using Reinforcement Learning (Unreal Engine 5)**

**Project Overview**
This project is about developing an autonomous self-driving car using Reinforcement Learning in a simulation environment created with Unreal Engine 5. The AI agent (vehicle) learns how to drive by interacting with the environment and improving its performance using rewards and penalties.

**Objectives**
The main objectives of this project are to create a realistic driving simulation, implement reinforcement learning for decision-making, train an AI agent to drive without human input, and evaluate its performance.

**Key Concepts Used**
The project is based on reinforcement learning, neural networks, simulation-based learning, and autonomous decision-making.

**Technologies Used**
Unreal Engine 5, Learning Agents Plugin, machine learning concepts, and simulation environment are used in this project.

**System Workflow**
First, a virtual environment is created in Unreal Engine. The AI agent observes the environment and collects data. A neural network processes this data and decides actions like steering and acceleration. Based on these actions, rewards or penalties are given. The system continuously learns and improves through training.

**Features**
The project includes a realistic simulation environment, AI-based autonomous driving, reward-based learning system, and performance evaluation.

**Results**
The system shows improvement in driving over time, reduced collisions, and better decision-making after training.

**Limitations**
The project is limited to simulation, may not fully match real-world conditions, and requires high computational resources.

**Future Scope**
Future improvements include using real-world sensors, applying advanced reinforcement learning techniques, multi-agent systems, and smart city integration.

**Learning Outcomes**
This project helped in understanding reinforcement learning, neural networks, Unreal Engine simulation, and AI-based system development.
